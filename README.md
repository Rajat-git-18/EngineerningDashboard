# Rajat Gupta — Portfolio

React Native / Mobile Engineer portfolio built with Next.js 15, TypeScript, and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Content source

Professional content is driven by the latest resume in `public/resume.pdf` and structured data in:

- `lib/site-config.ts`
- `lib/resume-data.ts`
- `lib/projects.ts`

## Deploy

Configured for Netlify via `netlify.toml` (`@netlify/plugin-nextjs`).

Set `NEXT_PUBLIC_SITE_URL` to your production URL.
